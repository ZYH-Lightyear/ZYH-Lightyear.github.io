# Publication author markers

The homepage uses `†` for co-first authors (equal contribution) and `✉` for corresponding authors. These are display-only: the approved BibTeX remains unchanged. Edit `co_first_authors` and `corresponding_authors` in each publication's front matter using names exactly as they appear in `authors`.
