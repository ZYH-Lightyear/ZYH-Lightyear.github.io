# Add a real notebook entry

Create `your-note.md` in this folder. Use this front matter, followed by Markdown:

```yaml
---
title: Your note title
layout: studio-entry
date: 2026-09-28
notebook: memory # memory, embodied, or making
description: A short description for search engines.
published: true
---
```

The entry appears in the reading-room list and in its book's dialog. Set `published: false`
for private drafts; do not place confidential material in a public repository even as a draft.
There are no fabricated articles or imported template posts in this collection.
