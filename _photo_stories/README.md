# Add a photo story

Put photographs in `images/journal/` and create a Markdown file here:

```yaml
---
title: Your photo story
layout: studio-entry
date: 2026-09-28
image: /images/journal/your-photo.jpg
image_alt: Describe the photograph.
description: A short description.
published: true
---
```

Add the story below the front matter. It will appear below the photo wall with a dedicated
reading page. Dates, locations, and image descriptions should be supplied by the author.
The initial archive image is the portrait already included in the existing homepage.
